# Public-IDL NDR oracle

The published-profile fixtures contain public types from MS-RDPEAR appendices 6.1–6.3 and MS-DTYP sections 2.3.5 and 2.3.10, with a test-only interface UUID and ACF serialization attributes.
The committed Rust tests include output from Windows SDK 10.0.26100.0 MIDL and the Windows RPC type-serialization runtime.
Unique-pointer IDs in exact encoding assertions are normalized to the Rust encoder's deterministic IDs; decoding also checks the original, unmodified vectors.
The big-endian signed-integer vector is independently constructed from MS-RPCE and NDR scalar rules, not generated by the little-endian SDK encoder.

In an x64 Visual Studio Developer PowerShell, change to this directory and run:

```powershell
midl /nologo /env x64 /out . ndr-oracle.idl
cl /nologo ndr-oracle.c ndr-oracle_c.c /link rpcrt4.lib /out:ndr-oracle.exe
.\ndr-oracle.exe
```

The seven output lines correspond to `independent_midl_negotiate_vector`, `independent_midl_nested_null_key_layout`, `independent_midl_pointer_to_pointer`, `independent_midl_conformant_credentials`, `independent_midl_ntlm_secret_enum_and_unicode`, `independent_midl_ntlm_fixed_keys_and_response16`, and `independent_midl_byte_aligned_ntlm_union_arm`.
The key fixture changes the unmarshalable public `void* reserved1` to `byte*` and always supplies NULL.
It proves the pointer slot and other field ordering only; it is not evidence for a non-null key referent type.

To reproduce the unresolved public-IDL blocker, run:

```powershell
midl /nologo /env x64 /out . void-referent.idl
```

This fails with MIDL2139: “type of the parameter cannot derive from void or void *”, naming `reserved1`.
No architecture-specific address or implementation-defined pointee is serialized by the Rust codec.
Delete generated headers, stubs, object files, and executables after running the fixture.

## Windows-native shape oracle

`native-oracle.idl` independently compiles public scalar, union, pointer, and `[ignore]` semantics using the pointer-root and NTLM-ID layout observed in installed Windows 11 26100 metadata.
It is not copied Microsoft implementation code and does not call an authentication package.
The partial unions preserve the relevant root alignment; the fixtures do not claim support for private operations or decrypted capture interoperability.

```powershell
midl /nologo /env x64 /out . native-oracle.idl
cl /nologo native-oracle.c native-oracle_c.c /link rpcrt4.lib /out:native-oracle.exe
.\native-oracle.exe
```

Its seven lines cover the four roots, ignored key slot, and double-pointer output.
Lines three and four differ only in the synthetic key's host pointer, which must not affect the serialized value.
The allocator zeroes memory so unspecified wire padding and the four-byte FC_IGNORE slot are reproducible.
Rust tests also decode arbitrary contents in that ignored slot; it is not a unique-pointer marker and never has a referent.
Exact-vector comparisons normalize only nonzero unique-pointer IDs, as in the published-profile fixtures.
Remove generated files after running; retain only the handwritten IDL, ACF, C source, and Rust vectors.
